# 台股研究與模擬操作系統（地端）

在自己電腦上執行的台股輔助系統：每天自動整理盤前資訊、提醒持股狀況、追蹤族群強弱，
並用一個「模擬帳戶」照固定規則操作，累積真實的前瞻紀錄，再決定要不要照抄。

- 所有數字由 Python 計算；本機 Ollama 只負責寫一兩句摘要，摘要裡出現原文沒有的數字就整段捨棄。
- 資料以官方來源為主（證交所、櫃買中心、公開資訊觀測站、期交所、Nasdaq），推送到 Discord。
- 只整理資料與驗證規則，**不是投資建議**；是否交易請自行判斷。

## 研究結論（截至 2026-10-23）

研究範圍是 2015 年起「上市＋上櫃電子股」，每月依當時的產業分類重建名單，**含之後下市的公司**（避免倖存者偏差）。

- **營收年增是最穩定的因子**：營收成長越強的股票，之後越容易漲。多數其他規則和族群排名扣掉成本後，都沒有贏過直接持有 0050。
- **模擬帳戶規則**（營收動能，詳見[模擬帳戶](#模擬帳戶)）：2018 年起歷史模擬年化約 +32%，0050 同期約 +27%，但最大回撤約 -46%（0050 約 -34%）。
  贏多少很看運氣（持股只有 2～3 檔），所以要靠前瞻紀錄驗證。
- **試過但讓結果變差、已不採用**：停利、帳戶虧損保險絲、連虧暫停、加入一年新高、持股 5～8 檔、不追高、60 日新低出場、兩種大盤過濾。
- **技術面訊號**（28 個）：只有「創一年／60 日新高」之後較強；長紅、爆量上漲、黃金交叉等追漲訊號，5 天內反而落後。
- **籌碼面訊號**（12 個，研究期 2018～2021、考卷期 2022 起只考一次）：只有「外資連買後轉賣」在考卷期仍有效（之後 5 天平均落後約 0.24%，小於交易成本）。
  「投信開始買」在研究期有效，考卷期已失效。

這些結論都是歷史統計；過去有效不代表未來有效。

## 安裝

需要 Windows、Python 3.12。在 PowerShell 執行：
```bash
git clone https://github.com/ShanHugo/stock_agent.git
cd stock_agent
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt pytest httpx
.venv\Scripts\python.exe -m pytest -q
```
接著：
1. 依下一節建立 `.env` 與 `portfolio.json`
2. 選用：安裝 [Ollama](https://ollama.com) 並執行 `ollama pull qwen3.5:9b`（用來寫摘要；沒有也能跑）
3. 試跑：`.venv\Scripts\python.exe scripts/morning_brief.py --dry-run`
4. 以**系統管理員身分**建立排程：`powershell -ExecutionPolicy Bypass -File scripts\register_tasks.ps1`

**換電腦**：GitHub 上只有程式碼。下面這些刻意不進 git，需要用隨身碟或私人管道搬（**不要上傳到 GitHub**）：

| 檔案 | 說明 |
|---|---|
| `.env` | Discord webhook 網址（等同密碼） |
| `portfolio.json` | 持股、提醒規則、風險設定 |
| `state/` | 模擬帳戶、前瞻紀錄、提醒狀態；**前瞻紀錄無法重建，務必搬** |
| `data/raw/`（選用） | 歷史資料快取；不搬的話研究工具要重新下載（數小時） |

搬完後在舊電腦停用排程，避免兩台都推送：`powershell -ExecutionPolicy Bypass -File scripts\register_tasks.ps1 -Disable`

## 設定

複製 `.env.example` 為 `.env`：

| 變數 | 說明 |
|---|---|
| `DISCORD_WEBHOOK_URL` | 盤前簡報、持股提醒、排程失敗通知（Discord 頻道 → 編輯頻道 → 整合 → Webhook） |
| `PAPER_BOT_WEBHOOK_URL` | 模擬帳戶專用頻道（沒填就送到上一個） |
| `PAPER_BOT_AUTO_SEND` | `1` = 模擬帳戶每天自動推送 |
| `OLLAMA_MODEL`、`OLLAMA_URL` | 本機模型，預設 `qwen3.5:9b`、`http://localhost:11434` |
| `TX_FEE_BPS` | 台股手續費（bps）：0.1425% × 券商折扣，2.8 折 ≈ 3.99 |

複製 `portfolio.example.json` 為 `portfolio.json`，填入持股、提醒規則與 `risk`（模擬帳戶與交易計畫用）：
```json
"risk": {"capital": 500000, "max_risk_per_trade": 0.03, "max_position_pct": 0.2, "max_total_risk": 0.08}
```
數字只是格式範例。欄位說明見 `src/app/alerts/portfolio.py` 與 `src/app/alerts/plans.py`。

## 每日排程

| 時間（平日） | 排程 | 內容 |
|---|---|---|
| 08:30 | morning_brief | 盤前簡報 |
| 09:30 | paper_exec | 模擬帳戶依盤中零股五檔成交 |
| 14:30 | check_alerts | 持股提醒 |
| 16:30 | forward_test | 前瞻測試紀錄 |
| 16:45 | sector_radar | 族群雷達 |
| 16:50 | paper_bot | 模擬帳戶收盤記帳、排定下一個交易日的單 |

- 以 Windows 工作排程器建立，**不需登入**即可執行（電腦要開著）；加 `-Disable` 全部停用。
- **休市防呆**：判斷依據是「交易所當天有沒有產生資料」，所以颱風假等臨時休市也能正確處理。
  - 09:30 成交：即時報價不是今天就略過，單子留到下一個交易日。
  - 14:30 持股提醒：沒有新收盤價就不推送。
  - 收盤後的排程：上市、上櫃都沒有當天行情，就不記帳、不重複推送。
  - 盤前簡報：只略過週末；平日國定假日仍會發送（美股照常交易）。
- **失敗通知**：每次執行結果記在 `state/scheduler/`；失敗時立刻推送「⚠️ 排程失敗」與最後幾行紀錄。
  沒執行到（例如電腦沒開）會在隔天盤前簡報列出。測試時設 `TASK_STATUS_NO_SEND=1` 只印出不推送。

## 本機操作台

雙擊 `scripts\start_console.cmd`，瀏覽器會開啟 http://127.0.0.1:8765 （只聽本機，同網路的其他裝置連不進來）。關掉黑色視窗就停止。

| 分頁 | 內容 |
|---|---|
| 持股總覽 | 最新收盤、未實現損益、台幣市值、停損停利價（只看，不推送） |
| 簡報與提醒 | 盤前簡報、持股提醒的預覽或推送 |
| 交易與計畫 | 記錄買賣、建立交易計畫並算可買股數、確認持股理由、交易檢討 |
| 研究卡 | 產生個股研究卡、管理觀察清單 |
| 選股研究 | 族群雷達（可展開個股）、前瞻測試結果、研究報告、重新執行研究 |
| 模擬帳戶 | 淨值與同資金 0050 走勢、持股、交易紀錄、成績單、暫停／恢復 |
| 設定與排程 | 排程狀態與最近輸出、編輯 `portfolio.json`（儲存前檢查格式，舊版自動備份） |

每個按鈕都是呼叫下面同一支命令列程式；推送、記錄交易等會改變資料的動作會先確認。

**用手機開操作台（Tailscale）**：
1. 電腦與手機都安裝 [Tailscale](https://tailscale.com) 並用同一個帳號登入（建立只有你自己裝置能連的私人網路）。
2. 以系統管理員身分重跑 `scripts\register_tasks.ps1`：操作台會變成開機就啟動的排程（`console`），不用登入 Windows。
3. 在電腦執行一次 `tailscale serve --bg 8765`，之後手機用 Tailscale 顯示的 `https://<電腦名稱>.<tailnet>.ts.net` 開啟。

操作台本身只聽 127.0.0.1，由 Tailscale 轉進來，區網和網際網路都連不到；只接受寫給本機或 `*.ts.net` 的請求。

**用截圖更新持股**（「持股總覽」分頁）：口袋證券沒有程式 API，改成上傳 App 的庫存截圖（可多張）；iPhone 截圖後選「拷貝並刪除」，長按貼上區貼上即可，不用存進相簿。
本機 Ollama 讀圖（截圖不送到外部），用截圖自己的「均價 × 股數 ≈ 總成本、股價 × 股數 ≈ 市值」驗算，列出差異由你勾選後才寫入，
寫入前自動備份；截圖沒有的持股不會自動刪除。電腦重開機後要登入過一次 Windows，Ollama 才會啟動。

## 每日功能

### 盤前簡報
```bash
python scripts/morning_brief.py --dry-run   # 只印出
python scripts/morning_brief.py             # 推送
```
- **隔夜美股**：S&P 500、那斯達克、費城半導體、VIX、美 10 年債、美元兌台幣、台積電 ADR 與 ADR 溢價。資料若停在前一天會標出「不是最新」。
- **台指期**：近月合約最近一次日盤，以及「之後」的夜盤（期交所把夜盤歸在下一個交易日，程式已處理）。
- **行事曆**：未來 7 天的 FOMC 與會影響股市的 BEA 發布（GDP、個人所得與支出等）；持股與觀察清單的除權息。
- **族群雷達**：前 5 名與最後 1 名，附歷史驗證結果。
- **族群新聞**：鉅亨網前一個交易日 14:30 以後的新聞，依族群歸類，由本機模型為新聞最多的族群各寫 1–2 句。
  出現原文沒有的數字，或「建議、買進、布局」等字眼就整段捨棄，只列標題。
- 持股狀態見 14:30 持股提醒，模擬帳戶見專用頻道，簡報不重複列出。

### 持股提醒
支援台股（上市／上櫃，含零股）與美股（含碎股，例如複委託 VOO）。門檻都在 `portfolio.json` 設定：
- **停損／停利／移動停損**：觸發時附賣出股數與預估損益（台股 ETF 證交稅 0.1%、股票 0.3%，美股無證交稅）。
- **從高點回落**：從近一年高點回落超過設定幅度，每跨過一個更深的門檻通知一次。
- **配置偏離**：依目標比例（例如台股：美股 = 50:50）偏離超過門檻時通知，並算出需要調整的台幣金額。
```bash
python scripts/record_trade.py buy 0050 12 108.5     # 買賣後記一筆，股數與均價自動更新
python scripts/check_alerts.py --dry-run             # 只印出
```
- 台股收盤價用證交所／櫃買官方行情補正，美股用 Nasdaq 官方歷史行情補正（Yahoo 偶爾缺值或整天不見）。
- 台股 14:00 前、美股紐約 16:30 前，當天 K 棒只是盤中價，不拿來判斷。

### 交易計畫與部位控管
操作個股（非 ETF）時，先寫計畫，依 `risk` 設定算出最多能買幾股：
```bash
python scripts/plan_trade.py new 2317 --stop 190 --thesis "AI 伺服器出貨成長" --invalid below_ma:60
python scripts/record_trade.py buy 2317 90 240        # 自動套用計畫；超出股數或風險預算會警告
python scripts/plan_trade.py review 2317              # 定期確認理由仍成立
python scripts/record_trade.py sell 2317 90 260       # 寫入交易日誌
python scripts/review_trades.py                       # 每月檢討（R 倍數、停損執行是否偏慢）
```
- 失效條件：`close_below:價格`、`below_ma:天數`、`time_stop:天數:最低報酬`、`revenue_yoy_below:門檻%:連續月數`。
- ETF 不需計畫；台股 00 開頭自動判定，美股 ETF 在持股標 `"etf": true`。

### 個股研究卡（上市公司）
```bash
python scripts/research_card.py 2330 2317
python scripts/research_card.py --watchlist     # 觀察清單＋持有的個股
```
把月營收、季度獲利、估值位置、法人與融資、價格位置整理成一張卡，只陳述數據。觀察清單與持股公布新月營收時，持股提醒會通知。

### 族群雷達
```bash
python scripts/sector_radar.py              # 最新一個交易日的族群排名
python scripts/sector_radar.py --backtest   # 歷史驗證：持有排名前 3 族群 vs 0050
```
- 族群分類來自櫃買中心產業價值鏈平台，定義在 `src/app/lab/themes.py`。
- 排序：營收年增、近 60 日漲跌、量能比、融資 20 日變化，四項族群中位數的跨族群排名平均。
- 個股參考標記（`src/app/lab/flags.py`）：**▲ 一年新高**（近 20 日創 250 日新高）、**▼ 外資轉賣**（近 5 日外資連買 5 天以上後轉賣）。
  都經過歷史驗證，但加進模擬帳戶規則的回測較差，所以只顯示、不交易。

### 模擬帳戶
依固定規則、你的風險設定與券商手續費，用模擬資金逐日操作電子股；不會真的下單。
```bash
python scripts/paper_bot.py --dry-run        # 只顯示，不寫入帳戶、不推送
python scripts/paper_bot.py --backtest       # 歷史模擬 2018 年至今（也是成績單的比較基準）
python scripts/paper_bot.py --scorecard      # 目前的成績單
```
**規則 v3**（2026-10-22 定案）：
- 進場：最近 2 個已公布月份營收都年增、站上 120 日線，依營收年增率由高到低；同一族群最多 2 檔；部位依 `risk` 計算。
- 出場：跌破停損（買價下方 10%）、跌破 120 日線、營收連 2 月年減；收盤漲到成本 +20% 後停損上移到成本價。
- 成交：隔天 09:30 依證交所盤中零股五檔模擬市價單；鎖漲停買不到、鎖跌停賣不掉。09:30 沒執行到則以開盤價補成交。

**成績單**：每月第一個交易日自動產生並推送。照抄標準在 2026-10-22 看到任何結果前訂定（`src/app/lab/scorecard.py`），四項都要達成：
滿 120 個交易日、完成交易 ≥ 20 筆、扣成本後贏同期 0050、最大回撤不比歷史同長度期間最差的 10% 還差。規則修改後評估期重新起算。

**前瞻觀察「大盤過濾」**：影子帳戶與模擬帳戶同資金、同規則，唯一差別是 0050 低於 200 日線時不買新股。
每日訊息附上兩邊淨值差；只觀察，不影響模擬帳戶。

暫停：操作台「模擬帳戶」分頁，或建立 `state/paper_bot/paused` 檔案。

### 前瞻測試
```bash
python scripts/forward_test.py --dry-run
```
規則固定為「營收動能、營收年增最高 20 檔」（代號 `rev_momentum_top20_v1`）。紀錄存在 `state/forward/records.jsonl`，只新增、不修改；
每筆在 5 天、20 天後以真實股價扣成本、與同期 0050 比較。

外資、投信買賣超與融資的「起漲／起跌」訊號，定義在 `src/app/lab/chips_signals.py`（看結果前訂定，不調整）。
